## [unreleased]

### Features

- Connection profiles for MQTT 3.1.1 and 5 over TCP, TLS, WebSocket and secure WebSocket, with automatic reconnect
- Live topic tree with counts, value previews, activity highlight, ordering, search, pause and keyboard navigation
- Value view with JSON colouring, hex dump, diff, history and MQTT 5 properties
- Decoders for text, JSON, hex, Base64, MessagePack, CBOR, Protobuf and Sparkplug B
- Publish panel with payload validation, history, presets and MQTT 5 properties
- Charts for numeric topics and JSON fields
- Session recording, JSON/CSV export and replay
- Optional on-disk message history
